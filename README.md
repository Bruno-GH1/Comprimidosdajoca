# Comprimidos da Joca

Aplicação instalável (PWA) pronta para GitHub Pages.

## Ficheiros (todos na raiz do repositório, sem pastas)

`index.html`, `sw.js`, `manifest.webmanifest`, `logo.svg`, `icon-192.png`, `icon-512.png`, `apple-touch-icon.png`

## Publicar

1. Cria um repositório novo no GitHub (ex.: `comprimidos-da-joca`, **Public**).
2. **Add file → Upload files** e arrasta todos os ficheiros acima.
3. **Settings → Pages → Deploy from a branch → `main` / `(root)` → Save**.
4. Abre o endereço `https://O-TEU-UTILIZADOR.github.io/comprimidos-da-joca/`.

## Pôr no ecrã inicial

- iPhone (Safari): Partilhar → Adicionar ao ecrã principal.
- Android (Chrome): menu ⋮ → Instalar aplicação / Adicionar ao ecrã principal.

## Importante

Comprimidos, histórico e fotos ficam guardados apenas no dispositivo. No iPhone, a app do ecrã inicial tem armazenamento separado do Safari, por isso começa vazia.
